# 販促コンペ 受賞企画書アーカイブ

宣伝会議「販促コンペ」の歴代受賞作品を一覧にしたもの。
社内で企画書をつくるときに、過去の受賞作から参考を探せるようにするための資料です。

## 見る

`index.html` を開くと、絞り込みつきの一覧が表示されます。

- **回次**（第1回〜第17回）
- **賞**（グランプリ／ゴールド／シルバー／学生賞／協賛企業賞／審査員個人賞）
- **課題企業**
- **キーワード**（タイトル・課題・受賞者）

各カードの「企画書PDFを開く」から、公式サイトの企画書に直接飛べます。

## 収録している内容

| 回次 | 状況 |
|---|---|
| 第16回・第17回 | 全受賞作品。企画書PDFへのリンクあり |
| 第14回・第15回 | 全受賞作品。SlideShare のスライドへのリンクあり |
| 第1回〜第13回 | グランプリのみ。それ以外は公式サイトで応募者ログインが必要 |

現在 163 作品。

## データ

- `data/awards.json` — 全作品のデータ本体
- 項目：`kai`（回次）、`year`、`category`（賞）、`award`、`judge`、`title`、`client`（課題企業）、`brief`（課題内容）、`winners`（受賞者）、`pdf`、`slide`、`thumb`、`page`

## 更新する

新しい回が発表されたら、以下で取り直せます。

```bash
python3 scrape.py   # 公式サイトから取得して data/awards.json を更新
python3 build.py    # index.html を作り直す
```

## 注意

- このリポジトリが持っているのは**一覧と公式サイトへのリンクだけ**です。企画書そのものは含んでいません。
- 出典：https://awardg.sendenkaigi.com/hansoku/history
